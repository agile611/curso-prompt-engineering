# Día 1 · Fundamentos y anatomía de un buen prompt

Esta jornada introduce las posibilidades y límites de los modelos de lenguaje y proporciona una metodología para redactar instrucciones claras.

## Objetivos

Al finalizar la jornada podrás:

- Explicar de forma básica cómo genera respuestas un LLM.
- Identificar las partes de un prompt.
- Transformar instrucciones ambiguas en solicitudes verificables.
- Elegir un caso de uso para el proyecto final.
