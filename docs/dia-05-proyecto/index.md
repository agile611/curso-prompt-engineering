# Día 5 · Proyecto final, validación y presentación

Completarás una solución útil y justificarás su calidad mediante pruebas y documentación.

## Objetivos

Al finalizar la jornada podrás:

- Completar el sistema de prompts.
- Ejecutar pruebas y corregir fallos prioritarios.
- Documentar resultados, limitaciones e instrucciones de uso.
- Presentar la solución y definir un plan de aplicación.

## Agenda

| Bloque | Duración |
|---|---:|
| Construcción final | 2 h |
| Pruebas y correcciones | 1,5 h |
| Documentación y entrega | 0,5 h |
| Presentaciones y revisión | 1,5 h |
| Transferencia al trabajo | 0,5 h |
| **Total** | **6 h** |
