# Día 3 · Evaluación, mejora y uso responsable

Diseñarás pruebas para comprobar la calidad de tus prompts y reconocerás riesgos de fiabilidad, privacidad y seguridad.

## Objetivos

Al finalizar la jornada podrás:

- Definir criterios de éxito observables.
- Crear casos normales, ambiguos y extremos.
- Comparar versiones de un prompt.
- Reconocer sesgos, información no verificada y riesgos de seguridad.

## Agenda

| Bloque | Duración |
|---|---:|
| Diseño de pruebas | 1,5 h |
| Refinamiento y versionado | 1 h |
| Fiabilidad, sesgos y privacidad | 1 h |
| Seguridad y prompt injection | 1 h |
| Laboratorio de evaluación | 1,5 h |
| **Total** | **6 h** |

- Un registro de errores.
- Una versión mejorada del conjunto de prompts.
