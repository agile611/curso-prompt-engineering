# Preparación y herramientas

## Requisitos

- Familiaridad básica con una interfaz de LLM.
- Ordenador con conexión a Internet.
- Acceso a al menos un modelo de lenguaje.
- Editor de texto para guardar prompts y resultados.

## Materiales

- Documentos sintéticos o anonimizados.
- Plantillas disponibles en esta web.
- Datos de práctica de `assets/datasets/`.

!!! warning "Datos sensibles"
    No utilices datos personales o confidenciales sin autorización.

## Funciones opcionales

El acceso a API y a un segundo modelo no es obligatorio.
La disponibilidad de temperatura y top-p depende de la plataforma.
