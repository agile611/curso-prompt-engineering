# Metodología

El curso combina explicaciones breves, demostraciones y práctica.

## Ciclo de trabajo

1. Resolver la tarea con un prompt inicial.
2. Analizar una técnica y sus limitaciones.
3. Modificar el prompt con un objetivo concreto.
4. Probarlo con diferentes entradas.
5. Documentar mejoras y errores.

Guarda las versiones de tus prompts y las respuestas obtenidas.
