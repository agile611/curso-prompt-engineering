# Rúbrica del proyecto

Valora cada criterio de 1 a 4.

| Criterio | Qué observar |
|---|---|
| Utilidad | Resuelve un problema concreto |
| Diseño | Define entradas, etapas y salidas |
| Validación | Incluye pruebas y criterios verificables |
| Seguridad | Contempla privacidad y revisión humana |
| Documentación | Permite reutilizar la solución |

## Escala

- **1:** insuficiente o sin evidencia.
- **2:** parcial; necesita mejoras.
- **3:** adecuado y documentado.
- **4:** sólido, comprobado y bien justificado.
