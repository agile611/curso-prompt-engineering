# Guía de presentación

Organiza la presentación en cinco partes:

1. Problema y usuario destinatario.
2. Diseño del flujo y técnicas utilizadas.
3. Demostración con una entrada de ejemplo.
4. Resultados de las pruebas y limitaciones.
5. Lecciones aprendidas y próximos pasos.

El bloque de presentaciones del día 5 está pensado para
aproximadamente seis equipos. Ajusta el formato al tamaño del grupo.
