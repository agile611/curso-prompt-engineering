# Glosario

- **LLM:** modelo de lenguaje de gran tamaño.
- **Prompt:** instrucciones y datos enviados al modelo.
- **Token:** unidad de texto que procesa el modelo.
- **Zero-shot:** instrucción sin ejemplos de resolución.
- **Few-shot:** instrucción acompañada de algunos ejemplos.
- **Alucinación:** contenido generado que parece plausible pero no está sustentado.
- **Prompt injection:** instrucciones en contenido no confiable que intentan desviar la tarea.
- **Versionado:** registro de cambios de un prompt o sistema.
