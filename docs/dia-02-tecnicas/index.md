# Día 2 · Técnicas de prompting y control de resultados

Aprenderás a escoger una técnica de prompting y a obtener respuestas con estructuras consistentes.

## Objetivos

Al finalizar la jornada podrás:

- Comparar instrucciones zero-shot y few-shot.
- Seleccionar ejemplos representativos.
- Descomponer tareas complejas y verificar resultados.
- Controlar roles, tono y formatos de salida.
